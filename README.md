# AutoCAD 2020 结构大样插件

仓库保留项目源码、依赖资源、构建脚本、发布文件及测试资料；本地 Codex 工作说明和配置不随项目上传。历史锚点的源码请使用各目录下的 `source/`，具体范围见[仓库发布说明](docs/仓库发布说明.md)。

## 使用方法（当前锚点 1.0.0.43）

以下命令均在 AutoCAD 2020 的命令行输入，输入后按回车执行。首次使用建议先复制建筑图纸，在副本中操作。

### 1. 加载插件

1. 保存图纸。如果已加载其他版本的插件，先关闭并重新启动 AutoCAD 2020。
2. 输入 `NETLOAD`，选择以下文件：

   ```text
   experiments/title-placement43/artifacts/Debug/AutoCADPlugin-1.0.0.43.dll
   ```
   换电脑后，在下载的项目文件夹中按上述相对路径查找。复制插件时，请一并保留 DLL 同目录下的 `Fonts/` 文件夹和 `ReferenceStyle.dwg`。
3. 输入 `SD_VERSION`，确认版本为 1.0.0.43，并核对加载路径。根目录 `artifacts/Debug/` 存放的是历史版本，43版应从上述目录加载。

### 2. 准备建筑大样和支撑区域

1. 打开建筑图纸副本，输入 `SD_SETUP`，创建插件所需的图层。
2. 将当前图层切换为 `SD-REGION`，用 `PLINE` 沿楼层梁、楼层板等支撑区域的边界绘制多段线，并用 `C` 闭合。每个支撑区域分别圈定；已有正确的闭合边界时，可直接使用。
3. 检查准备框选的范围，确保完整包含建筑轮廓、`SD-REGION` 支撑边界，以及需要继承的轴线和标高。当前流程将建筑1:100转换为结构1:25，图形放大四倍。

### 3. 一键生成完整结构大样（推荐）

1. 输入 `SD_GENERATE_ALL`。
2. 按提示依次点击建筑大样区域的第一个角点和对角点。选区应完整包含建筑大样、支撑边界、轴线和标高。
3. 在图纸中指定结构大样的插入点。选择较空的位置，为尺寸和图名留出空间。
4. 插件依次生成建筑轮廓、纵筋、点筋、尺寸、图名及纵筋和梁板指引。完成后检查图形和命令行提示，再保存图纸。

一键生成已包含完整流程，无需再执行下面的分步命令，也无需提前执行 `SD_REBAR_LABEL`。

### 4. 分步操作

需要逐步检查结果时，可在完成加载和支撑准备后，按下表操作。分步操作与一键生成选择一种即可。

| 顺序 | 命令 | 操作与结果 |
| --- | --- | --- |
| 1 | `SD_AUTO_DETAIL` | 依次指定建筑区域的两个角点和结构大样插入点。生成四倍结构轮廓及支撑，同时读取选区中的建筑轴线和标高。 |
| 2 | `SD_REBAR` | 框选上一步生成的完整结构轮廓及支撑，按回车确认，生成纵筋。 |
| 3 | `SD_POINT_REBAR` | 框选完整四倍结构轮廓、支撑及已有纵筋，按回车确认，生成点筋。 |
| 4 | `SD_DETAIL_LABEL` | 框选完整结构大样，按回车确认，生成尺寸和图名，并统一安排纵筋、梁板的文字指引。 |

如需单独生成或重新排版纵筋指引，执行 `SD_REBAR_LABEL`，框选包含纵筋、点筋、支撑及原梁板文字指引的完整结构大样，再按回车确认。完整流程中的 `SD_DETAIL_LABEL` 已包含这项处理。

### 5. 常见问题

| 提示或现象 | 检查方法 |
| --- | --- |
| 未找到 SD-REGION 闭合多段线 | 检查支撑边界所在的图层、是否闭合，以及是否完整落在选区内。 |
| 缺少轴线或标高 | 检查建筑源图和选区。早期生成的结构轮廓若未保存这些数据，需要从建筑源图重新执行43版 `SD_AUTO_DETAIL` 或 `SD_GENERATE_ALL`；后续标注命令无法自行补出缺失的建筑数据。 |
| 空间不足或图名放置失败 | 按提示检查周围障碍，选择更空的插入位置后重试。一键流程发生异常时，会回滚本次新建的大样。 |
| 点筋冲突或区间未补齐 | 根据命令行提示逐处核查。命令执行结束后，仍可能存在未补齐的区间。 |
| 加载的版本不符 | 保存图纸并重启 AutoCAD，重新执行 `NETLOAD`，再用 `SD_VERSION` 核对。切换 DLL 不会撤销已经画入图纸的实体。 |

## 历史记录：第一版结构大样命令

### 标记支撑区域

执行 `SD_SETUP` 创建标准图层，再在建筑大样中用 `SD-REGION` 图层绘制闭合的轻量多段线。每条闭合多段线表示一个楼层梁、楼层板等支撑区域。这些区域需要保留表达，但不需要自动配筋，也无需分别建立梁、板、墙、柱图层。

### 识别建筑轮廓

执行 `SD_AUTO_DETAIL`，框选建筑大样后指定结构大样插入点。插件读取 `WALL`、`COLUMN` 图层和绘制的 `SD-REGION` 闭合多段线，依据 `PUB_HATCH` 材料边界保留混凝土、剔除非混凝土，再将建筑1:100转换为结构1:25，放大四倍。

输出包括 `S-OTHER-THIN` 图层上的控制轮廓、支撑区域内的对角线叉号，以及 `S-TEXT` 图层上的“楼层梁”文字和引线。具体处理如下：

- `WALL`、`COLUMN` 轮廓统一映射到结构实例的 `S-OTHER-THIN` 图层，实体颜色设为白色。如果原图将填充斜线作为 WALL/COLUMN 图层上的真实线对象，程序会依据其所在的封闭填充区域剔除内部填充线，只保留边界。
- `SD-REGION` 的闭合多段线按原顶点和边逐段复制，不裁剪、延伸、推断相交或补线。区域内另行生成对角线叉号、“楼层梁”文字和引线。
- 混凝土 Hatch 边界按共线边及两侧区域关系筛选，只输出混凝土区域的外侧边。内部边和相邻混凝土区域的共边不重复输出。

多个 `SD-REGION` 区域的“楼层梁”标识优先放在各区域上方，再依次尝试右侧、左侧和下方。若候选位置与其他支撑区域或已有文字冲突，则换位，并用引线连接到支撑区域边界。

`SD-REGION` 仅表示楼层梁、楼层板等支撑区域。混凝土填充边界全部保留，非混凝土填充边界及其对应的 WALL/COLUMN 外轮廓不保留。轮廓命令不推断墙柱几何，也不生成纵筋或点筋；输出采用结构大样标准图层，实体颜色固定为白色。

当时的轮廓校准阶段只验证框选、建筑轮廓提取、支撑区域表达、比例转换和标准图层输出，尚不生成纵筋和点筋。后续记录更新至33版纵筋暂时验收、等待点筋新支线的阶段：SD_AUTO_DETAIL输出轮廓和支撑，SD_REBAR生成纵筋。

如果 AutoCAD 安装在其他目录，可通过项目属性指定路径：

```powershell
dotnet build .\AutoCAD二次开发.slnx -p:AutoCADInstallDir="C:\Program Files\Autodesk\AutoCAD 2020"
```

## 历史记录：实例1钢筋阶段（1.0.0.20）

加载 `artifacts\Debug\AutoCADPlugin-1.0.0.20.dll` 后，执行 `SD_VERSION` 核对版本。若已加载旧 DLL，先保存图纸并重启 AutoCAD，再加载新版；同名程序集无法在同一会话中可靠地热替换。

1. 已有四倍结构轮廓时，执行 `SD_REBAR`，框选完整结构大样轮廓，按回车确认。
2. 尚未生成轮廓时，先执行 `SD_AUTO_DETAIL`，再执行 `SD_REBAR`。
3. 程序匹配阶梯檐口、960宽竖向构造和斜屋面，添加7条连续纵筋和23个点筋。
4. 原有轮廓、支撑叉号和说明保持不变。一次UNDO可撤销本次新增钢筋；检测到原有钢筋时，程序拒绝叠加生成。

该版采用用户提供的实例1专用几何配筋规则，不适用于任意构件的自动结构设计。左侧檐口尺寸、坡度和支撑深度必须与参考一致。图形仅支持平移，屋面截断长度允许变化；匹配失败时不生成结果。旋转、镜像或不同檐口尺寸需另行增加规则。

纵筋采用目标DWG中的7条完整多段线路径，保留折点、收头及伸入支撑的锚固表达，不根据支撑框自行生成支撑钢筋。屋面部分按当前截断长度沿坡向调整。

点筋按用户确认的目标DWG样式绘制：由两个bulge=1的半圆多段线组成，中心线直径50、多段线宽度50，可见外径为100；不是普通直径50的CIRCLE或短直线。点筋图层为S-REIN-POINT，颜色为ACI30；纵筋图层为S-REIN，颜色为ACI6洋红，多段线宽35。两图层均使用连续线型，实体颜色、线型和线宽随层，图层线宽使用默认值。开启FILLMODE后显示实心。

来源记录为 `tests/fixtures/example1-target-geometry.json`。配筋数据内置于DLL，运行时不依赖桌面参考文件路径。`Example1RebarData.cs` 保存相对屋面转角的原始钢筋顶点，`Example1Rebar.cs` 负责轮廓核对、屋面长度适配和实体创建。

该阶段在AutoCAD 2020 accoreconsole中使用原始建筑DWG提取轮廓并放大四倍，检查了几何匹配、30个实体、纵筋宽35、点筋圆弧及宽度、实际外径100，以及重复布筋拦截和错误比例、空选择、多个大样的拒绝处理。验证输出见 `tests/rebar-results.txt` 和 `tests/example1-rebar-check.dwg`。

## 历史记录：支撑名称自动分类（1.0.0.21）

SD_AUTO_DETAIL按每个SD-REGION图形在X/Y方向的包围框计算宽高：高 > 2×宽时判为楼层梁，宽 > 2×高时判为楼层板；其余情况，包括恰好两倍，均保留为楼层梁。放大四倍不影响这一比例判断。已有图中文字不追溯修改，重新生成轮廓时才应用分类结果。
