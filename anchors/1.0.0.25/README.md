# 固定锚点：1.0.0.25

用户于2026-09-25确认25版效果并指定为新锚点。后续试验不符合预期时回退本版本，仅由用户明确指定新锚点；21、23版历史锚点保留。

- AutoCADPlugin-1.0.0.25.dll / .pdb：用户已确认的原发布文件，直接复制，不重新编译替换。
- source/及source-1.0.0.25.zip：25版源码、配置、发布脚本、测试及验证记录快照。
- manifest.json：本目录快照文件的SHA256校验清单。

稳定主项目src/AutoCADPlugin和根目录artifacts/Debug已提升为25版。26版实验仅修改experiments/offset50副本。

25版规则：对已放大四倍的轮廓扣除支撑、向内偏移50；支撑共用边对应的钢筋封口完全去除，其他部分保持原位置。共边判定与轮廓图使用一致的0.1距离容差。纵筋S-REIN、ACI6洋红、宽35、连续线型。此锚点不包含锚固，不生成点筋。

回退：撤销或删除试验钢筋，保留白色轮廓和支撑，保存图纸并重启AutoCAD，NETLOAD本目录25版DLL，以SD_VERSION核对。换DLL不会自动改变已经画出的图形。若需要恢复源码，先保留后续修改，再从source恢复到独立目录。
