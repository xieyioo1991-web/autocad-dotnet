# 固定锚点：1.0.0.26

用户于2026-09-25确认26版测试效果并指定为新锚点。本阶段名称为“锚固长度的调试”。后续测试若发现锚固长度代码不能满足需求，将在锚固长度规则上继续调整；在用户明确指定新的锚点前，以26版作为回退基准。21、23、25版历史锚点保留。

- AutoCADPlugin-1.0.0.26.dll / .pdb：用户已确认的原发布文件，直接复制，不重新编译替换；命令提示仍保留“试验26”。
- source/及source-1.0.0.26.zip：26版源码、配置、发布脚本、测试及验证记录快照。
- manifest.json：本目录快照文件的SHA256校验清单，不包含清单本身。

稳定主项目src/AutoCADPlugin和项目根目录artifacts/Debug提升为26版，后续试验使用独立副本。

本阶段沿用25版的偏移50及支撑接口开口规则，新增锚固：沿断口方向进入对应支撑，从支撑边界起算直锚1200；沿前进方向到支撑第一次出界处的剩余空间大于400时保持直锚，否则直伸800后向空间较大侧转90度，再延伸400。两侧空间相同时取逆时针侧。800或400放不下时保留该端原断口并报告，其他端照常锚固。全部长度为已放大四倍后的图形单位；纵筋保持S-REIN、ACI6洋红、宽35，不生成点筋。

既有验证记录包含40项AutoCAD 2020原生测试及正式26版SD_REBAR的样例、重复生成检查。本次归档仅核对源码、原DLL和快照的校验值，未改动算法或重新运行几何测试。完整规则、测试证据及限制见source/README.md。样例中两个弯段约20的共线重叠为本阶段规则的既有结果，未加入错位或避让规则。

回退：撤销或删除后续试验钢筋，保留白色轮廓和支撑，保存图纸并重启AutoCAD，NETLOAD本目录26版DLL，以SD_VERSION核对。换DLL不会自动改变已画出的图形。恢复源码前先保留后续修改，再从source恢复到独立目录。
