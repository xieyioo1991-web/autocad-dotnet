# 锚点26：锚固长度的调试

用户已确认26版为当前固定锚点，并将本阶段命名为“锚固长度的调试”。稳定主项目和根目录artifacts/Debug保存26版，完整快照位于anchors/1.0.0.26，原21、23、25版锚点保留。此目录保留26版开发及验证内容，后续试验仍在独立副本中进行。

后续测试若发现锚固长度代码不能满足需求，将在锚固长度规则上继续调整；在用户明确确认新的锚点之前，以26版作为回退基准。本次确认不改变已有算法和已发布DLL，命令提示中的“试验26”保留。

## 已确认的规则

1. 沿用25版：框选四倍结构轮廓、扣除支撑、向内偏移50、在支撑接口断开钢筋。
2. 每个断口沿其原钢筋方向进入对应的支撑。1200及800从进入支撑的边界处起算，现有断口到边界通常约50的距离另外补接，不计入锚固长度。
3. 尝试直锚1200。沿钢筋前进方向量到本支撑第一次出界处，直锚端之后的剩余距离大于400时保持直锚；小于或等于400（包括1200已超出构件）时改为弯锚。
4. 弯锚先从进入支撑的边界直伸800，再向两侧可用空间较大的一侧转90度并延伸400。两侧空间相同时采用原方向的逆时针侧。
5. 可用空间按纵筋中心线方向连续处于支撑内的长度计算，不能跨过凹区域缺口，也不能借相邻或远处另一支撑的空间。
6. 800直段或400弯段放不下时，该端保留25版断口，不画越界锚固；其他可锚固端正常生成。命令行报告未锚固端的纵筋序号、起终点、坐标及原因。沿原方向不能进入其对应接口、支撑重叠导致歧义时也报告原因。
7. 所有长度都是已放大四倍后的图形单位，不再乘4。纵筋保持S-REIN、ACI6洋红、ConstantWidth=35、连续线型；锚固以直角折点表达。本轮不生成点筋。

## 使用

1. 保存图纸并重启AutoCAD 2020。
2. NETLOAD项目根目录artifacts/Debug/AutoCADPlugin-1.0.0.26.dll，以SD_VERSION确认26版；本目录的同名版本DLL内容一致。
3. 先删除本次大样原有的25版洋红纵筋，保留白色轮廓、支撑框、叉号和文字。未锚固旧钢筋或重复结果会被检测并提示，避免叠加。
4. SD_REBAR框选完整四倍结构轮廓及支撑，回车生成。需要新轮廓时先执行SD_AUTO_DETAIL。
5. 查看命令行的直锚、弯锚、未锚固端数量。未锚固端保持断口，需调整规则或支撑条件。
6. 后续试验不符合预期时回退26：撤销/删除试验钢筋，保存并重启CAD，加载项目根目录artifacts/Debug/AutoCADPlugin-1.0.0.26.dll或anchors/1.0.0.26中的同名DLL。换DLL不会自动改变已有图形。

## 验证

已通过40项AutoCAD 2020 accoreconsole原生测试，包括原25项轮廓/偏移/开口检查和15项锚固检查。覆盖从支撑边界起算、余量恰好400与大于400、1200越界后弯锚、两侧空间比较、空间相同、800或400放不下、单端失败而另一端成功、凹区域中途出界、无关支撑不串用、闭合钢筋无锚固、旋转/镜像/逆序/大坐标、无法沿原方向进入支撑的局部接口等。

- tests/offset-results.txt：测试结果。
- tests/precision-interface.dwg：从原始建筑实例提取轮廓，将梁顶齐檐口后生成的两接口锚固测试图。2个直锚端、2个弯锚端，均已验证端点坐标。
- tests/anchorage-preview.png：根据生成DWG的实体坐标绘制，非CAD截图，省略文字。
- tests/precision-interface-command26-results.txt：正式26版DLL通过实际SD_REBAR生成2条纵筋，记录宽35和所有顶点；重复执行仍为2条。
- tests/offset50-sample-command26-results.txt：原实例另一个支撑布置生成1条纵筋，含1个直锚端、1个弯锚端。
- tests/point-contact-tagged-command26-results.txt：800宽支撑不能容纳内部800直段后再弯折时，相关端保留原断口，其他端仍能正常锚固。

样例中左侧两个弯段按相同800直段和向下400弯段生成，因此在同一位置有约20的共线重叠。这是当前规则组合的几何结果，本轮未自行更改锚长或进行钢筋错位。

## 实现与限制

SupportContact记录断口来自哪一条支撑共用边；SupportOpening保留25版开口结果并附带对应关系；PolygonRay按多边形交点计算连续内部区间；RebarAnchorage负责直锚/弯锚选择和逐端失败结果；OffsetRebar写入同一条连续多段线并检测旧25版结果和重复生成。

原有输入限制仍适用：仅处理Z=0直线轮廓，不支持圆弧及配筋区域内孔/嵌套边界；偏移50坍缩等几何错误会中止并回滚。选区必须包含完整支撑边界。支撑入口与余量按中心线计算，本轮未新增保护层、弯曲半径、搭接或避让碰撞规则。
