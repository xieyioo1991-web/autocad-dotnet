# 固定锚点：1.0.0.30

用户于2026-09-25明确确认30版为新的锚点。后续试验不符合预期时以30版为回退基准，原21、23、25、26版锚点保留。阶段名称仍为“锚固长度的调试”。

- AutoCADPlugin-1.0.0.30.dll / .pdb：用户确认的原发布文件，直接复制，不重新编译替换，命令仍显示试验30。
- source/及source-1.0.0.30.zip：30版源码、发布脚本、项目约定、测试及验证记录。
- manifest.json：本目录文件的SHA256校验清单，不包含清单本身。

稳定主项目src/AutoCADPlugin和根目录artifacts/Debug提升为30版，后续规则在experiments/offset50独立试验。本锚点仍使用普通直锚1200、倒U两腿直锚1200；普通800+400弯锚优先向下，钝角斜筋从定位交点转竖直向下800，有U型定位线向U腿内侧40，无U型距梁侧50。包含50内偏、支撑开口、梁顶倒U型及计算支撑合并、阴角边长>600才断开和延伸400遇筋停止规则。完整规则和限制见source/README.md。

原验证包含95项AutoCAD 2020后台检查，以及正式DLL在3个样例中生成4/4/3条纵筋、重复执行不叠加、宽35的命令验证。本次归档校验原发布文件与源码快照，不重新编译。用户同一轮提出的1000直锚、上下水平筋差异锚固和小区域取消下筋属于下一版试验，不包含在本锚点内。

回退：撤销或删除后续试验纵筋，保留轮廓和支撑，保存并重启AutoCAD，NETLOAD本目录30版DLL，用SD_VERSION核对。换DLL不会自动改变已有图形。恢复源码前先保留后续修改，再从source恢复到独立目录。
