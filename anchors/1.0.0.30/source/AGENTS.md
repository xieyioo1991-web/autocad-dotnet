# 项目开发约定

本文件适用于整个项目，包括插件、几何算法、测试、诊断工具和构建发布相关代码。

## 当前固定锚点

- 用户已确认 **1.0.0.30** 为当前阶段回退锚点。本阶段名称为 **“锚固长度的调试”**。源码快照、DLL、PDB 和校验清单位于 `anchors/1.0.0.30/`，不得覆盖。原21、23、25、26版锚点保留。
- 仅在用户明确确认新的进展并指定新锚点后更新锚点。试验通过编译或测试不等于用户接受。
- 钢筋规则试验在 `experiments/offset50/` 独立副本开展，稳定主项目及 `artifacts/Debug` 保持30版。失败时停止采用试验版本，回到30；恢复其他目录前先保留用户新增修改。
- 后续测试若发现锚固长度代码不能满足需求，应在锚固长度规则上继续调整。30版冻结规则包含1200直锚、800+400优先向下弯锚、倒U型及钝角斜筋转竖直800等；后续用户提出的1000直锚及上下水平筋差异规则应在新试验中实现，不能改写30版锚点。没有新的具体要求时不自行更改数值或开启下一轮试验。

- 编写、修改或审查 C# 时，使用 `dotnet-csharp`：`C:/Users/Administrator/.codex/skills/dotnet-csharp/SKILL.md`。按技能路由读取相应参考资料。
- 实现和审查时，同时使用 `dotnet-csharp-code-smells`：`C:/Users/Administrator/.codex/skills/dotnet-csharp-code-smells/SKILL.md`。重点检查资源所有权、异常处理、重复枚举、重复逻辑和边界条件。

- 本地技能路径失效时，先查找已安装技能的新位置；无法读取时如实说明，不宣称已经使用。

## AutoCAD 兼容性与资源管理

- 当前宿主为 AutoCAD 2020，项目目标框架为 .NET Framework 4.7.2。采用技能建议前核对目标框架和宿主 API；不要仅为了套用现代示例升级运行时或引入新依赖。
- 区分事务管理的数据库对象与自行创建的临时对象，明确所有权和释放时机。命令失败时回滚未提交的图形修改。
- 不在后台线程直接访问 AutoCAD 文档和数据库对象。不要为同步 CAD 命令强行引入异步模式或依赖注入框架。
- 不静默吞掉导致轮廓缺失或结果不完整的异常；能恢复时明确记录跳过原因，不能恢复时给出失败信息。
- 不为替换被锁定的 DLL 强制结束用户的 AutoCAD 进程；使用独立构建目录和版本化发布，提示保存并重启后加载。

## 验证与交付

- 对本次改动涉及的代码使用上述两项技能检查，不因此未经请求全面重构已验证功能。
- 编译通过只证明可构建。几何、配筋或 AutoCAD API 行为改变时，按需使用样例 DWG 和 AutoCAD 2020 后台引擎验证，明确区分编译验证与运行验证。
- 比较位置、尺寸、图层、实体类型和数量；有必要时进行图形对比。不要只验证输出与实现自身相同。
- 保留用户参考 DWG，不覆盖原图。比例、支撑区域和钢筋图形标准以用户已确认的要求为准。
- 发布遵循现有版本号与 `scripts/Publish-Plugin.ps1` 流程。交付说明本次变化、已完成验证及适用范围。
