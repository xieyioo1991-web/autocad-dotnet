# 项目开发约定

本文件适用于整个项目，包括插件、几何算法、测试、诊断工具和构建发布相关代码。

## 当前固定锚点

- 用户于2026-09-25暂时验收 **“纵筋布置阶段”**，当前阶段转为 **“点筋布置阶段（等待用户在新支线给定规则）”**。本次只归档、建立阶段定位和同步已验收代码；不书写点筋布置规则、不实现点筋、不代替用户创建新支线。
- **1.0.0.33** 为纵筋布置阶段的已验收锚点，也是后续点筋工作的回退基准。源码快照、原发布DLL/PDB、验证记录和SHA256清单位于 `anchors/1.0.0.33/`，不得覆盖。原21、23、25、26、30版锚点继续保留。
- 稳定主项目 `src/AutoCADPlugin/` 和根目录 `artifacts/Debug/` 已同步为33版；`experiments/offset50/` 保留本轮纵筋试验及测试。后续从33版独立副本开展点筋试验，不改写稳定基线及冻结快照。恢复任何目录前先保留后续修改。
- 建筑轮廓阶段按33版现行代码单独定位，入口是 `SD_AUTO_DETAIL`；纵筋阶段入口是 `SD_REBAR`。先读 `docs/阶段索引.md`，按 `docs/建筑轮廓阶段.md` 或 `docs/纵筋布置阶段.md` 定位。不能把纵筋内部的 `OffsetRebar.CreateOutline` 当成建筑轮廓提取入口。
- 33版包含普通直锚及倒U两腿1000、水平成对上筋800+400弯锚/下筋600直锚、小区域取消下筋且上筋600直锚、自由竖段下端再减50，以及此前的倒U、斜筋转竖直800、阴角等规则。所有规则以冻结源码和说明为准。
- 此前“锚固长度的调试”仅指历史子阶段，已经结束；锚固仍是纵筋布置中可按新需求调整的子规则。旧归档中的阶段误记以本文件和阶段索引更正，不改写旧快照。
- 仅在用户明确确认新的进展后更新锚点。编译或测试通过不等于用户接受；本次33版的接受依据是用户明确暂时验收纵筋布置阶段。没有新要求时不自行更改数值或开启试验。旧 `Example1Rebar` 中的点筋模板和 `Standards` 里的历史点筋常量，不代表下一阶段已经确认的布置规则。

## AutoCAD 兼容性与资源管理

- 当前宿主为 AutoCAD 2020，项目目标框架为 .NET Framework 4.7.2。采用技能建议前核对目标框架和宿主 API；不要仅为了套用现代示例升级运行时或引入新依赖。
- 区分事务管理的数据库对象与自行创建的临时对象，明确所有权和释放时机。命令失败时回滚未提交的图形修改。
- 不在后台线程直接访问 AutoCAD 文档和数据库对象。不要为同步 CAD 命令强行引入异步模式或依赖注入框架。
- 不静默吞掉导致轮廓缺失或结果不完整的异常；能恢复时明确记录跳过原因，不能恢复时给出失败信息。
- 不为替换被锁定的 DLL 强制结束用户的 AutoCAD 进程；使用独立构建目录和版本化发布，提示保存并重启后加载。

## 验证与交付

- 对本次改动涉及的代码使用上述两项技能检查，不因此未经请求全面重构已验证功能。
- 编译通过只证明可构建。几何、配筋或 AutoCAD API 行为改变时，按需使用样例 DWG 和 AutoCAD 2020 后台引擎验证，明确区分编译验证与运行验证。
- 比较位置、尺寸、图层、实体类型和数量；有必要时进行图形对比。不要只验证输出与实现自身相同。
- 保留用户参考 DWG，不覆盖原图。比例、支撑区域和钢筋图形标准以用户已确认的要求为准。
- 发布遵循现有版本号与 `scripts/Publish-Plugin.ps1` 流程。交付说明本次变化、已完成验证及适用范围。
