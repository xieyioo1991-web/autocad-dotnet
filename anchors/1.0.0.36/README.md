- 原DLL：`AutoCADPlugin-1.0.0.36.dll`，SHA256 `E3EC359E37D489A60B28ABA3D994AD87057F18436ED67BAEEC361CB1ABE22652`。

- 既有证据：167项回归/几何检查和9份DWG验证。36有已知漏布及交点拥挤问题，详情见source/README.md与source/tests/precision-interface-distribution36.txt。

36包括梁顶600高度规则、短斜接区域取消U并从原梁顶直锚1000、小反坎有U但不作延伸；点筋实际外径100、固定角点、400收尾和≤800间距。单点冲突会使整个区间取消，穿越交点可能被误固定；这些现象是37待修问题，锚点中不改。
