# 点筋布置阶段：36版固定角点与沿筋分布

当前独立试验：`experiments/point-distribution/`，版本1.0.0.36；用户已授权实现，尚未验收为新锚点。稳定33、全部冻结锚点及35试验目录不变。

完整规则、边界条件、使用方法和验证记录见 [36版试验说明](../experiments/point-distribution/README.md)。35阶段说明原文保存在 [35说明副本](../experiments/point-distribution/baseline35-notes/点筋布置阶段.md)。

## 当前规则

1. 目标DWG样式保持不变：S-REIN-POINT，颜色30，Continuous，图层默认线宽，实体ByLayer；两个bulge=1的半圆组成闭合轻量多段线，中心线直径50、宽50，实际外径100。
2. 阳角来自实际纵筋的转折和交点。普通弯锚、斜筋转竖直锚固，以及36短竖段转入梁的锚固段，不参与固定角点生成。倒U顶部两角保留。
3. 固定外端角点；阴角延伸交点只固定“水平延伸段＋竖向原段”一侧红点，青点候选重排。固定点不移动。
4. 原始打叉支撑禁止完整点筋圆形侵入。普通点排在打叉边缘或有效梁顶延伸区边缘外400收尾；倒U本身点排以实际梁顶为边界，上部允许布点。400为圆心到有限边缘线的最短距离。
5. 没有支撑边界而遇真实纵筋自由端时，圆心到端点的实际距离400；中途转折不是端部。
6. 固定头尾之间，沿与纵筋内侧平行的点筋中心路径等分。路径长L，区间数n=ceil(L/800)，间距L/n≤800，尽量接近800。每个固定点均作为分段控制点。
7. 点圆在材料轮廓内，与宽35纵筋内侧边缘相切，圆心距纵筋中心线67.5。倒U顶部两点允许压到其他锚固筋，其余点不扩大此例外。
8. 固定点、400收尾、碰撞检查不能同时满足时，保留固定点并提示冲突坐标，该区间未补齐。不得静默跳点后宣称仍满足800间距；也不自行移动固定点、放宽400或允许压筋。

上述尺寸均为放大四倍后的值。钢筋交角与轮廓不是同一种角，轮廓只提供材料范围及越界判断，不作为点筋角点来源。

## 36版同时增加的纵筋规则

从原梁顶起算左右竖直轮廓高度，取较大值并按一位小数比较：接斜段时，>600才有倒U且作为延伸支撑；≤600无U、不作延伸，斜线偏50与竖线偏50交点转竖向，从原梁顶直锚1000。无斜段且≤600为小反坎，仍有倒U，两腿1000，但不作延伸支撑。无斜段且>600保持原有U与延伸区规则。

`GeometrySupports`用于扣除已单独生成U的区域；`EffectiveSupports`才是其他纵筋锚固、普通点排400收尾所用的有效支撑。小反坎不能因为几何扣除而变成锚固支撑。短斜接竖直锚固空间不足时保留原断口并提示，不改弯锚。

## 验证及操作

167项AutoCAD 2020后台回归/几何检查通过；9个实际DWG命令样例生成23/23/7/6/1/0/7/8/2点，重复执行数量稳定、原纵筋实体不变；9份输出DWG再次只读检查样式、外径、相切及禁入。具体记录在试验目录tests中。

样例23点并不表示所有区间都已补齐：左侧阴角自由端400收尾压到竖筋、倒U腿400收尾压到内侧锚固筋等位置会提示。见 `tests/precision-interface-distribution36.txt`。这些冲突需要后续规则决定，36不会自行放宽现有约束。

保存并重启AutoCAD，NETLOAD `experiments/point-distribution/artifacts/Debug/AutoCADPlugin-1.0.0.36.dll`，SD_VERSION核对。清理本大样旧点筋；测试梁顶600新规则还需清理旧洋红纵筋，再依次SD_REBAR、SD_POINT_REBAR。原四倍轮廓、支撑和标注保留。仅支持宽35、XY平面的直线纵筋多段线；任意手工改形锚固段的身份未必能够重新计算匹配，不宣称支持所有手工钢筋。
