## 冻结的关键数值

全部为放大四倍后的图形尺寸：内偏50；纵筋S-REIN、ACI6洋红、连续线型、多段线宽35；普通及倒U两腿直锚1000；普通剩余空间阈值400；弯锚800+400，优先向下；水平成对上筋弯锚、下筋直锚600；梁侧轮廓宽高均小于600的小区域取消下筋，上筋仅直锚600，自由竖段下端再减50；斜筋按既定定位线转竖直向下800；90度阴角相邻轮廓边至少一条>600才断开，延伸最多400遇筋截停。尺寸比较遵循当前DrawingPrecision实现。

所有锚固从进入支撑边界处起算（斜筋转竖直段从转折点量800），放不下按现有失败策略反馈；倒U两腿直锚不足中止整次生成。几何限制、端点识别及优先级以冻结代码为准。

## 已有验证与历史实现

33版已有128项AutoCAD 2020后台检查通过；正式DLL的6组命令验证生成4/4/3/1/1/1条纵筋，重复运行数量稳定。记录冻结于锚点 `source/tests/offset-results.txt` 和6份 `*-command33-results.txt`。本次验收归档校验源码与原发布文件，未改变算法、未为验收改版号或重新编译。

`Example1Rebar.cs`、`Example1RebarData.cs` 和 `StructuralPathExtractor.cs` 是保留的早期实现，当前 `SD_REBAR` 不调用它们。其中的点筋模板、以及 `Standards` 中已有点筋常量，不能作为未来点筋布置算法已经完成或已获确认的依据。点筋规则由用户在新支线另行给定。
