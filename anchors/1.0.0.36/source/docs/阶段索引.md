## 阶段衔接

`建筑图 + SD-REGION支撑 → SD_AUTO_DETAIL → 四倍轮廓及支撑 → SD_REBAR → 纵筋 → SD_POINT_REBAR（36版试验）→ 固定角点及沿筋分布点筋`

两个阶段通过DWG实体衔接。轮廓线带 `SD_OUTLINE_ROLE=Contour`，支撑闭合多段线带 `Support`；叉号、引线和文字不带这两种标记。未来修改图层、角色标记或支撑分类时，要检查对下游纵筋读取的影响。比例仅在建筑轮廓输出时乘4，纵筋的50、600、800、1000等值已是放大后的尺寸。

## 新支线接续与回退

新支线先读取根目录 `AGENTS.md` 和本索引，再从33版完整源码副本开始。33版已包含建筑轮廓和纵筋；无需拼接不同历史版本。现有DLL内的“试验33”提示保留，归档未为改名重新编译。

恢复时先保存后续新增修改，从锚点 `source/` 取出完整代码，在独立目录构建；加载时保存并重启AutoCAD，NETLOAD锚点33版DLL，以 `SD_VERSION` 核对。切换DLL不会撤销图纸里已经生成的实体。
