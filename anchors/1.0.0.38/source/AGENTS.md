- 点排尺寸沿用36：固定点不移动。普通点排在真实打叉或有效梁顶延伸区边缘外400收尾；U自身的点排只以真实打叉区域为边界。400是圆心到有限边缘线的最短距离；无边缘而遇真实自由端时，是圆心到该端点的实际距离400。连续转折不是自由端。固定头尾之间沿点筋中心路径等分，间距≤800、区间数取最少；所有值均为四倍图尺寸。
- 38已确认补充：真实纵筋端部实际接到有限横向/斜向纵筋时，以交接处内侧相切位置收尾，不再退400；附近贯穿交点或延长线交点不算端部接触。横排优先均布：竖排用交接相切位置计算间距，落在完整横排上的竖排尾点由横排统一安排，不额外固定或添点；中间点保留。没有有效横排覆盖时尝试恢复尾点，冲突则提示。真实自由端、支撑400和固定角点规则继续保留。
- 38建筑指引：`SupportLabelLayout`按本次支撑、提取轮廓及已放文字/引线选择水平文字底线、竖直指引或斜段加水平底线；`DetailWriter`输出原生Line/DBText。保持字高250、S-TEXT/S-OTHER-THIN、白色以及原打叉和角色标记。空间不足时提示；新样式由SD_AUTO_DETAIL生成，不自动替换旧图指引。见 `experiments/point-layout38/README.md`。
- 37试验放宽跨路径碰筋限制：点筋仍与所属纵筋路径内侧相切，不侵入所属路径的其他段，但允许在图面上与其他路径的穿越纵筋或锚固筋重叠。此改动用于验证图一、图二漏布问题；此前仅U顶部两点允许压筋，现在扩大为本次试验规则，不能称为已经验收的新通用规范。真实支撑禁入、材料轮廓不越界及点筋间不重叠仍保留。
- 36版梁顶：按原梁顶以上左右竖直轮廓较高边判断（尺寸按一位小数比较）。接斜交区域且高度>600：U＋有效延伸区；高度≤600：无U、无有效延伸区，斜线内偏50与竖线内偏50的交点转竖直，从原梁顶边缘向下直锚1000，空间不足保留断口并提示。无斜交且高度≤600：小反坎，保留U两腿1000，不作有效延伸区。等于600不按>600处理。
- 小反坎的普通筋几何扣除区 `GeometrySupports` 与锚固/点筋收尾使用的 `EffectiveSupports` 分开，禁止将小反坎误当虚拟支撑。短斜接竖段的特殊锚固在 `ShortBeamTopAnchorage`；新增类型 `BeamTopStraight` 不参与固定角点生成。

## AutoCAD 兼容性与资源管理

- 当前宿主为 AutoCAD 2020，项目目标框架为 .NET Framework 4.7.2。采用技能建议前核对目标框架和宿主 API；不要仅为了套用现代示例升级运行时或引入新依赖。
- 区分事务管理的数据库对象与自行创建的临时对象，明确所有权和释放时机。命令失败时回滚未提交的图形修改。
- 不在后台线程直接访问 AutoCAD 文档和数据库对象。不要为同步 CAD 命令强行引入异步模式或依赖注入框架。
- 不静默吞掉导致轮廓缺失或结果不完整的异常；能恢复时明确记录跳过原因，不能恢复时给出失败信息。
- 不为替换被锁定的 DLL 强制结束用户的 AutoCAD 进程；使用独立构建目录和版本化发布，提示保存并重启后加载。
