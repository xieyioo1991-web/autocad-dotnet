## 阶段衔接

`建筑图 + SD-REGION支撑 → SD_AUTO_DETAIL → 四倍轮廓及支撑 → SD_REBAR → 纵筋 → SD_POINT_REBAR（38版试验）→ 真实转折固定点及沿筋分布点筋`

两个阶段通过DWG实体衔接。轮廓线带 `SD_OUTLINE_ROLE=Contour`，支撑闭合多段线带 `Support`；叉号、引线和文字不带这两种标记。未来修改图层、角色标记或支撑分类时，要检查对下游纵筋读取的影响。比例仅在建筑轮廓输出时乘4，纵筋的50、600、800、1000等值已是放大后的尺寸。

## 新支线接续与回退

新支线先读取根目录 `AGENTS.md` 和本索引，按用户指定的基准取独立完整副本。本轮38从37复制，建筑提取与纵筋算法沿用；建筑指引排版改动见建筑轮廓阶段的38增量。冻结DLL保留原版本提示，归档没有为改名重新编译。

38回退时先保存后续修改和测试图副本，再保存并重启AutoCAD，NETLOAD `anchors/1.0.0.36/AutoCADPlugin-1.0.0.36.dll`，以 `SD_VERSION` 核对。清理38点筋后按36重画，36纵筋可以保留。切换DLL不会撤销图纸里已生成的实体；需要恢复源码时从36锚点 `source/` 复制到新的目录，不覆盖后续试验或冻结文件。
