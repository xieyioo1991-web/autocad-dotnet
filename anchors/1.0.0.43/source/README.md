# 43版：修复图名放置误判

1.0.0.43从42独立复制；38锚点和42发布文件保留。仍属尺寸标注与图名试验，尚未验收。

## 原因及修复

用户截图提示“图名下方没有足够空间……本次标注已回滚”。错误来自DetailTitle最后的图名布局，随后SD_GENERATE_ALL整套事务回滚。

42将所有障碍都转换为整个GeometricExtents矩形，再测试图名是否重叠。因此大图框、空的闭合多段线、斜线和某些尺寸的空白包围区域可能被当成实际占用。旧布局只检查5排×5处，横移最多1400、向下最多2000，也会漏掉近旁可用空间。

已用完整原生大样加一个空矩形框复现相同报错（tests/reproduced-42.txt）；相同用例在43完整标注通过（tests/frame-checks.txt）。截图没有提供当时DWG，不能据此断定用户现场究竟是哪一个实体触发；此次修复的是已确认且可复现的算法缺陷。

- TitleObstacles按真实线段/多段线边界、尺寸线和可见文字检查；空线框不再视为整块填充，线宽计入避让。
- 图名仍保持实例文字、编号1、圆圈、线宽和字体，预留1800不变。先选原居中位置；受阻时根据障碍边缘寻找邻近候选，不限于固定25格。
- 横移范围最多为图名半宽加200（至少1400），向下额外搜索最多6000；按距原位置距离排序，不移到任意遥远位置凑成功。
- 真正可见的文字、线条及填充仍阻挡；不能放置时提示首选位置障碍句柄/图层，建议选择更空的插入点，并回滚。
- 未改变建筑提取、轴线标高、纵筋、点筋、主尺寸线及指引规则。AnnotationInk对圆弧等未知形状仍保守按范围处理，本次没有扩展曲线精确相交。

## 使用

保存并重启AutoCAD，NETLOAD artifacts/Debug/AutoCADPlugin-1.0.0.43.dll，SD_VERSION确认43。
保留DLL旁Fonts与ReferenceStyle.dwg。继续用SD_GENERATE_ALL，完整框选建筑大样和SD-REGION、轴线、标高，再指定插入点。分步命令保留。
