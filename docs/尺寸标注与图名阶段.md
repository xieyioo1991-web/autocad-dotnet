# 尺寸标注与图名阶段

本规则文档于2026-09-26在42版建立，目录`experiments/detail-layout42/`。41已发布但主尺寸链逐条避让导致错层，42据用户反馈修正；41目录保留。当前整体锚点为43，38保留为点筋阶段的历史锚点，39至42没有单独设为锚点。

样式证据见[实例1样式基准](尺寸标注与图名样式基准.md)，完整使用说明及测试见[42说明](../experiments/detail-layout42/README.md)。早期“待确认”问题均已有用户答复，不能继续按只读样式/图名草稿阶段处理。

## 已确认规则

- 图名形式及内容照抄参考：檐口大样图、下划线、圆圈和1；保留下面点筋说明。下方留竖轴/轴号空间，不编造无样例的轴号。
- 从本次建筑图继承轴线位置、标高基准位置及数值，套结构样式。本例是10.200，不能改为参考10.150。
- 数据读取在SD_AUTO_DETAIL框选建筑时完成，并写入结构图关联实体；后续标注命令只消费这些数据。旧轮廓没有的建筑数据不从结构图猜测。
- 主要水平尺寸在上，主要竖向尺寸在左。每个主方向的尺寸线必须共线。对应方向有轴线时定位轴线，否则定位梁板边缘；定位站点进入同一主尺寸链。
- 短台阶、凹凸槽等细碎局部独立标注，不混入主链。首轮根据相邻边的相对长短分类，没有把配筋600阈值套入尺寸规则。
- 先生成原生尺寸，再移动文字避让；不因文字拥挤而逐条移开主尺寸线，不改变测量端点。TSSD_25_100的DIMLFAC=0.25、DIMSCALE=1、DIMRND=5、DIMTXT=300保持参考。
- 完成尺寸后布置图名、钢筋规格和梁板指引。标高文字可移动，数值和符号基准不动；用户其他既有文字作为障碍保留。纵筋每条完整多段线仍有一条%%1328@150指引。

## 命令

- **SD_GENERATE_ALL**：框选建筑大样和SD-REGION、轴线、标高，指定插入点，单事务完成全部阶段。尺寸之后才生成纵筋/梁板指引。
- 分步：**SD_AUTO_DETAIL → SD_REBAR → SD_POINT_REBAR → SD_DETAIL_LABEL**。
- SD_REBAR_LABEL保留，可单独生成纵筋指引；在完整流程中不需要先执行它。SD_DETAIL_LABEL会更新已有本插件指引，并非永久叠加。

一键命令仍要求设计人员预先给定SD-REGION支撑。异常失败回滚整套新大样；原配筋规则可恢复的未补齐提示继续报告。

## 代码定位

以下位于42的src/AutoCADPlugin/：

| 文件 | 职责 |
| --- | --- |
| Commands.cs、ArchitecturalDetail.cs | 建筑框选与事务入口；支撑/轮廓/轴线/标高共用源基点放大4倍 |
| ArchitecturalGuides.cs | DOTE/AXIS轴线、DIM_ELEV标高读取和样式套用 |
| CompleteDetail.cs | 一键流水线，复用原纵筋及点筋服务 |
| DetailReference.cs | 复制打包参考图中的原生样式、图名、标高与尺寸对象；同名冲突隔离 |
| DetailDimensionPlan.cs | 实际结构轮廓测量点、轴线/支撑定位、主局部尺寸分类 |
| DetailDimensions.cs | 固定主尺寸链及文字移动，不能移动尺寸线去避让 |
| DetailTextLayout.cs | 标高文字与已定尺寸避让 |
| DetailTitle.cs | 图名原生组复制和下方预留 |
| DetailAnnotation.cs、RebarAnnotation.cs | 尺寸及图名完成后的共同指引布局 |
| DetailAnnotationIdentity.cs | SD_DETAIL_ANNOTATION关联支撑句柄；角色Axis/Elevation/Title/MainDimension/LocalDimension |
| AnnotationInk.cs | 原生尺寸和可见块属性字形/线段避让 |

DetailReference的内部缓存名SD_REFERENCE_41和样式冲突后缀_SD41延续41定义，表示兼容缓存，不代表加载版本；以SD_VERSION为准。

## 42验证及边界

真实发布DLL的一键命令已由AutoCAD2020运行；一键/分步几何一致，主链共线、重复更新、失败回滚、原生文字避让、复制关联已验证。既有194项配筋/支撑检查及13项指引检查通过；38锚点177文件校验无变化。

原生支持的轴线/标高图元之外会提示未识别，不虚构数值。当前样例有两条既有点筋排布未补齐提示，仍保留供设计人员核查。尺寸分类与排版为试验，测试通过不代表用户验收。图名预留1800及主链外距800是试验布局参数，不是新增设计规范。
