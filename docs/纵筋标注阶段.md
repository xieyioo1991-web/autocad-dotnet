# 纵筋标注阶段

> 当前整体锚点为用户于2026-09-26确认的[1.0.0.43](../anchors/1.0.0.43/README.md)，现有纵筋标注功能随43冻结。下文记录39版首次实现时的定位与测试状态；其中待验收及回退38的描述是历史记录，不改变43的锚点身份。

2026-09-26启动，基准为用户暂时验收的38点筋阶段，冻结位置 `anchors/1.0.0.38/`。当前39在 `experiments/rebar-annotation39/`，属于待用户查看的试验。

入口：`SD_REBAR_LABEL`。输入是已有纵筋、点筋、轮廓和支撑的完整结构大样及其梁板标注，不再次放大、不重新配筋。

一条完整纵筋多段线对应一个 `%%1328@150` 指引，文字和引线规格沿用实例1钢筋规格标注。标注布局与梁板文字一起规划，允许移动这三类文字和引线；其他文字作为障碍。参考字体TSSD_Label：tssdeng.shx＋hztxt.shx、250高、0.7宽。钢筋指引S-OTHER-THIN随层绿色连续线，文字S-TEXT随层白色。

| 修改内容 | 39版源码位置 |
| --- | --- |
| 选择范围、命令返回、事务失败回滚 | `RebarAnnotationCommands.cs` |
| 每根钢筋读取、原生字形测量、写入 | `RebarAnnotation.cs` |
| 空位选择、文字和引线避让、共同重排 | `AnnotationLayout.cs` |
| 实例1字体/图层/线型、字体依赖 | `AnnotationStyle.cs`、`assets/Fonts/` |
| 原38未关联梁板标注迁移 | `LegacySupportAnnotations.cs` |
| 标注关联与重复执行 | `AnnotationIdentity.cs` |

这些文件均位于 `experiments/rebar-annotation39/src/AutoCADPlugin/`。不要把本阶段的布局逻辑写进点筋的 `DistributedPointRebar` 或建筑轮廓的 `ArchitecturalOutlineExtractor`。

完整规则、适用范围、测试及使用方法见[39版说明](../experiments/rebar-annotation39/README.md)。本轮未要求标注点筋规格、尺寸、标高和轴号，不计算钢筋选型。用户未验收39前不得更新锚点。
