## 阶段衔接

建筑图＋SD-REGION支撑 → SD_AUTO_DETAIL → 四倍轮廓/支撑及建筑轴线标高 → SD_REBAR → 纵筋 → SD_POINT_REBAR → 点筋 → SD_DETAIL_LABEL → 尺寸/图名及逐根纵筋、梁板文字最终共同避让。SD_REBAR_LABEL仍可单独使用；最终命令会更新其旧标注。

建筑轮廓核心提取器是ArchitecturalOutlineExtractor。不能把纵筋内部OffsetRebar.CreateOutline误当建筑图提取入口。建筑提取、比例和标准基线与早期锚点一致；33支撑分类/文字表达与30一致，角色标记与23/25/26/30一致；详见建筑轮廓定位文档。38仅改进建筑指引排版。

轮廓实体带SD_OUTLINE_ROLE=Contour，支撑闭合多段线带Support；叉号、引线和文字不带这两种角色。39标注带SD_ANNOTATION句柄关联，不能作为轮廓识别输入。原图比例仅在SD_AUTO_DETAIL乘4，后续50、400、600、800、1000等值均为已放大尺寸。

## 标注范围与恢复

39每条完整S-REIN纵筋多段线配一条%%1328@150指引，字体和线型图层按实例1钢筋规格指引。梁板文字参与共同重排，其他文字作为障碍。每条多段线的所有连续弯折视为一根，不按其小线段分别标注。39不计算钢筋规格、不改变38配筋坐标。

后续细节试验需要回退时，先保留试验文件，保存并重启CAD，NETLOAD anchors/1.0.0.43/AutoCADPlugin-1.0.0.43.dll，保留同目录Fonts和ReferenceStyle.dwg，以SD_VERSION核对。从43图纸副本继续；切换DLL本身不会撤销已经画入DWG的修改。需要恢复源码时，从43冻结source/复制到另一个独立目录，不覆盖后续试验和冻结文件。若明确要回到不含后续标注的点筋阶段，才使用38锚点及对应图纸副本。

40的楼层板没有可见叉线，仍带Support角色，继续用于纵筋锚固和点筋禁入。配筋代码不得以可见对角线数量推断是否为支撑。


42一键入口SD_GENERATE_ALL复用建筑、纵筋、点筋服务，最后定尺寸线、移动文字、安排指引。一次建筑框选与插入点，无需反复选择中间结果；失败回滚本次新建大样。完整流程不必提前执行SD_REBAR_LABEL。
