# 42版：主尺寸链共线与一键生成

1.0.0.42是独立试验版，等待用户查看效果；38仍为已验收锚点。41及历史源码/DLL保留。

## 加载与使用

保存图纸并重启AutoCAD 2020，NETLOAD本目录`artifacts/Debug/AutoCADPlugin-1.0.0.42.dll`，执行`SD_VERSION`确认1.0.0.42。DLL旁必须保留`Fonts/`及`ReferenceStyle.dwg`。不要只复制DLL。

建筑图中先保留设计人员已画好的SD-REGION闭合支撑边界。需要新建该图层时用SD_SETUP。

**一键：SD_GENERATE_ALL**。框选完整建筑大样（包含轴线、标高和SD-REGION），指定空白插入点。顺序为：轮廓/支撑与轴线标高→纵筋→点筋→尺寸/图名→逐根纵筋及梁板指引。无需再逐个框选中间结果。各阶段共用一个事务，失败时回滚本次大样；配筋算法已有的可恢复提示仍会显示，不能把有提示的区间视为已补齐。

**分步保留：SD_AUTO_DETAIL → SD_REBAR → SD_POINT_REBAR → SD_DETAIL_LABEL**。SD_REBAR_LABEL也可单独使用，但完整流程最后一项会生成或更新这些指引，无需预先执行。

## 本轮修改

- SD_AUTO_DETAIL负责从建筑选区读轴线和标高，和轮廓一起放大4倍输出。结束时报告识别数量，缺失则提示。SD_DETAIL_LABEL使用这些已关联数据，不再访问建筑图；旧图若没读取到数据，需从建筑图重新生成。本例保留2条轴线、10.200标高，不套成参考图的10.150；无样例的轴号不生成。
- 主水平尺寸线统一在图上方，同一个Y；主竖向尺寸线统一在左侧，同一个X。不再逐条外移尺寸线，也不额外增加与主链重叠的轴线总尺寸。轴线或梁板边缘作为主链定位点。
- 先定尺寸线，再移动尺寸文字避让，测量端点不动。细碎台阶保留独立局部尺寸。标高文字可避让，数值及三角符号基准位置不动。其后生成图名、纵筋和梁板指引；一键流程只生成这套指引一次。
- 复制实例图名和圈内1；尺寸/标高/轴线/图名样式仍沿用参考。未更改纵筋和点筋算法。

## 代码定位

| 文件 | 用途 |
| --- | --- |
| Commands.cs / ArchitecturalDetail.cs | 共用建筑框选入口、4倍轮廓、支撑及轴线标高输出 |
| ArchitecturalGuides.cs | 建筑轴线位置、标高数值和符号关联，结构样式输出 |
| CompleteDetail.cs | 单事务一键流水线，最后才安排指引 |
| PointRebarGeneration.cs | 抽取原点筋命令服务，供分步与一键共同调用 |
| DetailDimensionPlan.cs | 轮廓尺寸测量点、主链轴线/支撑定位、局部分类 |
| DetailDimensions.cs | 固定主链位置，仅移动尺寸文字 |
| DetailTextLayout.cs | 标高文字避让，不移动标高基准 |
| DetailAnnotation.cs | 尺寸→文字→图名→钢筋/梁板指引，重复更新 |
| AnnotationInk.cs | 原生尺寸、块及可见属性的字形/线段检查 |

## 验证与范围

- AutoCAD 2020原生运行一键和分步：几何对比一致，均4条纵筋、26个点筋、15条尺寸、2条轴线、1处10.200标高、4条纵筋指引、2条梁板指引及1组图名。
- 主尺寸两方向共线、实际测量比例0.25、实例字体/字高、文字与尺寸线避让、重复执行、事务回滚、复制大样后关联独立均验证通过。
- 194项既有几何/配筋/支撑检查、13项纵筋指引检查、3个无轴线变体、9项图名检查通过。详细记录在tests/；发布DLL另以真实SD_GENERATE_ALL命令运行，诊断属性读取0错误。
- 本样例保留原点筋算法2条“轮廓截断且没有固定端”的提示，本轮没有静默删除提示或宣称其已修复。
- 当前建筑轴线支持DOTE或图层名包含AXIS的原生水平/竖直Line；标高支持DIM_ELEV的DBText与开口三角多段线。未扩展任意嵌套块、代理对象或其他图层命名识别。
- 局部尺寸分类仍是短台阶相对邻边长度的首轮试验；图名预留1800、主链距整体外包范围800是排版参数，须由实际试图继续评价。编译/测试通过不代表已验收。
