# 42版加载

保存图纸并重启AutoCAD 2020，NETLOAD本目录的AutoCADPlugin-1.0.0.42.dll，输入SD_VERSION核对。
保留DLL旁Fonts文件夹和ReferenceStyle.dwg。

一键命令：**SD_GENERATE_ALL**。
框选完整建筑大样（包含已画好的SD-REGION支撑、轴线和标高），指定空白插入点。

分步命令保留：SD_AUTO_DETAIL → SD_REBAR → SD_POINT_REBAR → SD_DETAIL_LABEL。
SD_REBAR_LABEL也保留，但完整流程不必预先执行，最后统一生成钢筋及梁板指引。

轴线标高在SD_AUTO_DETAIL阶段读取。缺少这些数据的旧轮廓，需从建筑图重新生成。只加载新DLL不会自动修改旧图。
42为待看效果的试验版，38锚点未覆盖。
