# 试验27：90度阴角断开及延伸

用户已确认26版为当前固定锚点，其阶段名称为“锚固长度的调试”。稳定主项目和根目录artifacts/Debug保存26版，完整快照位于anchors/1.0.0.26，原21、23、25版锚点保留。此目录现在进行27版独立试验，尚未成为新锚点。

后续测试若发现锚固长度代码不能满足需求，将在锚固长度规则上继续调整；在用户明确确认新的锚点之前，以26版作为回退基准。本轮保留26版锚固计算，在锚固后的纵筋上应用阴角断开规则。

## 本轮新增规则（用户已确认）

1. 90度阳角保持弯折；配筋区域外轮廓的90度阴角处断开纵筋，两端各自沿原方向继续直伸最多400。400为放大四倍后的数值，从原偏移纵筋转角交点起算。
2. 阴角按照闭合配筋区域的凹角判别，再匹配到纵筋路径；非90度转角、支撑锚固的弯头不拆开。判断支持顺逆序、旋转、镜像和已有0.1图形单位范围内的微小坐标误差。
3. 延伸中心线遇到本次生成的纵筋时停在第一个交点，包括同一条原纵筋的其他部分、其他区域纵筋及26版锚固段。白色轮廓、支撑叉号、文字和点筋不作为碰撞对象。当前命令为完整轮廓重新生成，不把图中另外手画的纵筋加入碰撞计算；已有25/26版或相同结果会提示先删除，避免叠加。
4. 多个新延伸端采用等速生长的确定性判定：交叉时后到交点的一端停止，同时到达则两端都停止；共线相向延伸在相遇处停止。已被提前截去的延伸部分不作为障碍，不依赖选择次序。
5. 断开以开放多段线表达，角点处两根直行钢筋可以交叉，不再连接成原来的90度弯头；没有新增人工缺口。纵筋图层、洋红颜色和宽35不变。

## 沿用26版的锚固规则

1. 沿用25版：框选四倍结构轮廓、扣除支撑、向内偏移50、在支撑接口断开钢筋。
2. 每个断口沿其原钢筋方向进入对应的支撑。1200及800从进入支撑的边界处起算，现有断口到边界通常约50的距离另外补接，不计入锚固长度。
3. 尝试直锚1200。沿钢筋前进方向量到本支撑第一次出界处，直锚端之后的剩余距离大于400时保持直锚；小于或等于400（包括1200已超出构件）时改为弯锚。
4. 弯锚先从进入支撑的边界直伸800，再向两侧可用空间较大的一侧转90度并延伸400。两侧空间相同时采用原方向的逆时针侧。
5. 可用空间按纵筋中心线方向连续处于支撑内的长度计算，不能跨过凹区域缺口，也不能借相邻或远处另一支撑的空间。
6. 800直段或400弯段放不下时，该端保留25版断口，不画越界锚固；其他可锚固端正常生成。命令行报告未锚固端的纵筋序号、起终点、坐标及原因。沿原方向不能进入其对应接口、支撑重叠导致歧义时也报告原因。
7. 所有长度都是已放大四倍后的图形单位，不再乘4。纵筋保持S-REIN、ACI6洋红、ConstantWidth=35、连续线型；锚固以直角折点表达。本轮仍不生成点筋。

## 使用

1. 保存图纸并重启AutoCAD 2020。
2. NETLOAD本目录artifacts/Debug/AutoCADPlugin-1.0.0.27.dll，以SD_VERSION确认27版。
3. 先删除本次大样原有的洋红纵筋，保留白色轮廓、支撑框、叉号和文字。旧25/26版钢筋或重复结果会被检测并提示，避免叠加。
4. SD_REBAR框选完整四倍结构轮廓及支撑，回车生成。需要新轮廓时先执行SD_AUTO_DETAIL。
5. 查看命令行的阴角断开数、延伸端数、遇筋截停数，以及直锚、弯锚、未锚固端数量。未锚固端保持断口，需调整规则或支撑条件。
6. 后续试验不符合预期时回退26：撤销/删除试验钢筋，保存并重启CAD，加载项目根目录artifacts/Debug/AutoCADPlugin-1.0.0.26.dll或anchors/1.0.0.26中的同名DLL。换DLL不会自动改变已有图形。

## 实现与限制

SupportContact记录断口来自哪一条支撑共用边；SupportOpening保留25版开口结果并附带对应关系；PolygonRay按多边形交点计算连续内部区间；RebarAnchorage负责26版直锚/弯锚选择和逐端失败结果；RebarCornerBreak识别阴角并拆分路径；RebarExtensionCollision计算延伸截停；OffsetRebar写入多段线并检测旧25/26版结果和重复生成。

原有输入限制仍适用：仅处理Z=0直线轮廓，不支持圆弧及配筋区域内孔/嵌套边界；偏移50坍缩等几何错误会中止并回滚。选区必须包含完整支撑边界。阴角截停和支撑入口、余量均按中心线计算，本轮未新增保护层、弯曲半径或搭接规则，也不重新调整既有锚固段的相互重叠。
