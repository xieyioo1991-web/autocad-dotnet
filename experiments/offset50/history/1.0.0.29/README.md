# 试验29：梁顶倒U型优先规则

用户已确认26版为当前固定锚点，其阶段名称为“锚固长度的调试”。稳定主项目和根目录artifacts/Debug保存26版，完整快照位于anchors/1.0.0.26，原21、23、25版锚点保留。此目录现在进行29版独立试验，尚未成为新锚点。27、28版源码及旧验证结果保存在history对应版本目录，旧DLL按发布流程归入artifacts/Debug/历史版本。

后续测试若发现锚固长度代码不能满足需求，将在锚固长度规则上继续调整；在用户明确确认新的锚点之前，以26版作为回退基准。29版先执行梁顶强规则，再执行其余配筋区域的偏移、开口、锚固及阴角规则。

## 本轮强规则（用户已确认）

1. 按原支撑长宽比分辨楼层梁与楼层板，与现有标注共用分类代码：宽>2倍高为楼层板，其余按原默认楼层梁。楼层板不触发此规则。
2. 从梁的顶部水平边向WCS的+Y方向检查相连的竖直轮廓。梁上部是否还连接斜屋面、侧板等，不影响先生成倒U型。脱离梁的上方轮廓、仅点接触或下方区域不触发；多个梁分别处理。同一梁上可识别互不重叠的窄竖直段。
3. 左右轮廓高度不同时先取较高侧标高，将矮侧在计算中向上补齐，形成水平顶边；再按两侧及水平顶边向内50生成倒U型。两腿保持竖直，顶部不得按原两侧不同高度斜连。白色原轮廓不改动。
4. 倒U型每条腿从原楼层梁顶边界向下直锚1200，不使用普通纵筋的400余量判断，也不自动改成弯锚。任一腿的原梁内连续直锚空间不足1200，或上部区域放不下偏移50的U型时，提示原因并中止整个命令，避免部分生成。凹梁缺口不能跨越。
5. U型生成后，将补齐高度的上部矩形区域与原梁多边形求并集，作为同一个计算支撑，供其余区域的断口锚固。内部原梁顶边不再截断可用空间；不把两个矩形的外包框直接当支撑，不填充并集之外的肩部或空隙。此合并不写入新的边界或叉号，也不增加支撑标注。
6. 倒U型是独立开放多段线，S-REIN、洋红、宽35。上部区域不再重复生成普通轮廓纵筋；其余阴角延伸遇到U型可截停，但U型本身不参与阴角拆分。

## 沿用28版的阴角规则

1. 90度阳角保持弯折；90度阴角相邻两条原轮廓直边至少一条严格大于600才断开，两条均小于或等于600则保持弯折。600是原尺寸150放大四倍后的数值。边长从偏移50前的配筋区域轮廓读取，到相邻真实转角为止；同一直边上的共线分段合并计长，不借用下一转角之后的边。阈值仅使用1e-6浮点误差保护，600.01即满足条件。
2. 符合条件的阴角映射到向内偏移50后的钢筋交点，两端各自沿原方向继续直伸最多400，仍从该钢筋交点起算。非90度转角、支撑锚固的弯头不拆开。判断支持顺逆序、旋转、镜像和已有0.1图形单位范围内的微小坐标误差。
3. 延伸中心线遇到本次生成的纵筋时停在第一个交点，包括同一条原纵筋的其他部分、其他区域纵筋及26版锚固段。白色轮廓、支撑叉号、文字和点筋不作为碰撞对象。当前命令为完整轮廓重新生成，不把图中另外手画的纵筋加入碰撞计算；已有25/26版或相同结果会提示先删除，避免叠加。
4. 多个新延伸端采用等速生长的确定性判定：交叉时后到交点的一端停止，同时到达则两端都停止；共线相向延伸在相遇处停止。已被提前截去的延伸部分不作为障碍，不依赖选择次序。
5. 断开以开放多段线表达，角点处两根直行钢筋可以交叉，不再连接成原来的90度弯头；没有新增人工缺口。纵筋图层、洋红颜色和宽35不变。

## 其余纵筋沿用26版的锚固规则

1. 沿用25版：框选四倍结构轮廓、扣除支撑、向内偏移50、在支撑接口断开钢筋。
2. 每个断口沿其原钢筋方向进入对应的支撑。1200及800从进入支撑的边界处起算，现有断口到边界通常约50的距离另外补接，不计入锚固长度。
3. 尝试直锚1200。沿钢筋前进方向量到本支撑第一次出界处，直锚端之后的剩余距离大于400时保持直锚；小于或等于400（包括1200已超出构件）时改为弯锚。
4. 弯锚先从进入支撑的边界直伸800，再向两侧可用空间较大的一侧转90度并延伸400。两侧空间相同时采用原方向的逆时针侧。
5. 可用空间按纵筋中心线方向连续处于支撑内的长度计算，不能跨过凹区域缺口，也不能借相邻或远处另一支撑的空间。
6. 800直段或400弯段放不下时，该端保留原断口，不画越界锚固；其他可锚固端正常生成。命令行报告未锚固断口的坐标及原因。沿原方向不能进入其对应接口、支撑重叠导致歧义时也报告原因。此逐端失败规则适用于普通纵筋；倒U型使用上述强制直锚规则。
7. 所有长度都是已放大四倍后的图形单位，不再乘4。纵筋保持S-REIN、ACI6洋红、ConstantWidth=35、连续线型；锚固以直角折点表达。本轮仍不生成点筋。

## 使用

1. 保存图纸并重启AutoCAD 2020。
2. NETLOAD本目录artifacts/Debug/AutoCADPlugin-1.0.0.29.dll，以SD_VERSION确认29版。
3. 先删除本次大样原有的洋红纵筋，保留白色轮廓、支撑框、叉号和文字。旧25/26版钢筋或重复结果会被检测并提示，避免叠加。
4. SD_REBAR框选完整四倍结构轮廓及支撑，回车生成。需要新轮廓时先执行SD_AUTO_DETAIL。
5. 查看命令行的倒U型数量、普通纵筋直锚/弯锚/未锚固数量，以及阴角断开数、延伸端数、遇筋截停数。普通未锚固端保持断口，需调整规则或支撑条件；U型1200直锚不足则整个命令不生成。
6. 后续试验不符合预期时回退26：撤销/删除试验钢筋，保存并重启CAD，加载项目根目录artifacts/Debug/AutoCADPlugin-1.0.0.26.dll或anchors/1.0.0.26中的同名DLL。换DLL不会自动改变已有图形。

## 实现与限制

SupportClassification统一支撑分类；BeamTopRegion从材料边界识别梁顶竖直段并验证连续相接；BeamTopRebar生成强制倒U型、校验1200直锚并合并计算支撑。之后SupportOpening识别新的支撑接口，RebarAnchorage执行普通直/弯锚，RebarCornerBreak与RebarExtensionCollision处理阴角和截停。OffsetRebar仅写入纵筋实体。完全被上部计算支撑消化的独立竖直段允许仅输出倒U型。

原有输入限制仍适用：仅处理Z=0直线轮廓，不支持圆弧及配筋区域内孔/嵌套边界；偏移50坍缩等几何错误会中止并回滚。选区必须包含完整支撑边界。新识别按WCS的竖直方向和梁最高处水平顶边进行，不把倾斜柱段当作竖直段；同一梁优先识别两侧延续的整个区域，再考虑内部相接的窄段。阴角截停和锚固长度均按中心线计算，未新增弯曲半径、搭接或钢筋错位规则。
