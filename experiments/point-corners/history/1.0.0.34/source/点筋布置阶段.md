# 点筋布置阶段：34版阳角试验

本轮从已验收33版建立独立副本 `experiments/point-corners/`。稳定主项目和锚点33不变；34未验收。用户在本轮明确给定以下规则，并确认梁顶延伸区域允许点筋及倒U顶部点筋可压到其他锚固筋。

## 当前规则

1. 实际目标DWG只读检查了23个点筋实体：S-REIN-POINT图层、颜色30、CONTINUOUS线型、图层默认线宽；实体为ByLayer，两个bulge=1的半圆组成闭合轻量多段线，中心线直径50、宽50，实际外径100。此处沿用用户此前确认的实际外径100，不把它改成外径50。
2. 本命令生成的完整点筋圆形不得侵入原始打叉支撑。即使圆心在外，只要圆边越入支撑也拒绝；允许圆边恰好与支撑边界外切。
3. 沿用纵筋的BeamTopRegion/BeamTopRebar识别梁上方未打叉的竖直延伸区域，该区域允许布点，先保留倒U顶部两个阳角点筋。排除判断使用OriginalSupports，不能使用已经合并梁顶区域的EffectiveSupports。
4. 本轮仅布置纵筋形成的阳角点筋，不布置沿边分布点筋。圆处于结构轮廓内部和纵筋内侧，需与形成角的两条有限纵筋边缘相切。圆心至纵筋中心线距离为50+35/2=67.5。直角、非直角采用同一角平分线计算。
5. 倒U顶部点筋仍与倒U的水平顶边和竖直侧边相切，用户明确允许其压到其他斜筋转下来的锚固筋，不为避让而向内移动。这一例外不允许侵入原始打叉支撑或越出材料轮廓；其他普通阳角仍检查纵筋碰撞。
6. 空间不足、切点落在实际线段以外、圆不完全在轮廓内的候选跳过并反馈数量。点筋之间避免相互重叠。重复运行对相同样式点筋去重，不重画已有纵筋。

## 代码定位

下列文件均在 `experiments/point-corners/src/AutoCADPlugin/`。

| 内容 | 文件 / 方法 |
| --- | --- |
| 新命令、选择、输入纵筋校验、事务和输出信息 | `PointRebarCommands.cs`：`PointRebar`，命令SD_POINT_REBAR |
| 阳角候选、内切圆、禁入及碰撞、倒U例外 | `CornerPointRebar.cs`：`Create`、`TryTangent`、`IntersectsSupport` |
| 原生实心点筋样式、图层、重复运行去重 | `PointRebarWriter.cs`：`Write` |
| 复用的梁顶区域及支撑身份 | 原33版 `OffsetRebar.Create`、`BeamTopRegion`、`BeamTopRebar`；计算上下文，不写入纵筋 |
| 回归和新增点筋测试 | `tests/OffsetChecks.cs`、`tests/PointCornerChecks.cs` |

当前候选来自同一多段线的转折及不同纵筋的重合端点；不自动把互不相接的直线延长求交，也不为每个十字交叉新增四个点。只支持已放大四倍、宽35、XY平面的直线纵筋多段线。须框选完整轮廓、支撑和已有纵筋；纵筋算法的轮廓输入限制继续适用。

## 使用与验证

保存并重启AutoCAD，NETLOAD试验目录 `artifacts/Debug/AutoCADPlugin-1.0.0.34.dll`，SD_VERSION确认版本。需要新纵筋时先用SD_REBAR生成；已有33版纵筋可保留。执行SD_POINT_REBAR，框选完整四倍轮廓、支撑及纵筋，回车。

140项AutoCAD后台检查通过（包含原128项纵筋检查），并核对原生点筋的图层、实体类型、宽度、外径及重复运行。6个命令样例最终生成9/10/5/2/1/0个点筋，纵筋实体数据保持不变，重复运行数量稳定。倒U两角按用户最新确认保留；短竖段只有50的极小样例不满足相切条件，0点为预期。

最终样例为 `tests/*-points34-final.dwg`；`*-points34.txt`为最终命令实体记录；无final后缀的DWG是确认倒U重叠例外前的中间结果。`points-preview34.png`按最终实体坐标绘制，非CAD截图。原参考DWG未保存覆盖。绘图仅验证本轮阳角规则，分布点筋待用户后续给定。
