# 36版试验：点筋分布及梁顶600高度判断

用户于2026-09-25授权实现。本目录为35试验的独立副本；稳定33及所有锚点未改。36未被用户验收为新锚点。35说明修改前副本在 `baseline35-notes/`，35代码与DLL仍在 `../point-corners/`。

## 使用

1. 保存图纸并重启AutoCAD 2020，NETLOAD本目录 `artifacts/Debug/AutoCADPlugin-1.0.0.36.dll`，用SD_VERSION核对。
2. 在测试图副本上清理本大样旧点筋。验证梁顶600新规则时，也清理旧洋红纵筋，保留四倍轮廓、支撑及标注。
3. SD_REBAR框选完整四倍轮廓和支撑，生成36纵筋。SD_POINT_REBAR再框选完整轮廓、支撑及纵筋。
4. 查看命令行提示。400收尾或等分点有冲突的区间保留固定点，不会强行补齐。重复执行不增加相同点；选中与新布局不一致的旧点筋会提示先清理。

## 纵筋规则增量

所有尺寸均为已放大四倍的图上尺寸，比较时保留一位小数。

| 原梁顶以上竖直区域 | 倒U | 作为梁的有效延伸支撑 |
| --- | --- | --- |
| 接斜段，左右竖边较高者>600 | 有，保持既有U规则 | 是 |
| 接斜段，较高者≤600 | 无 | 否 |
| 无斜段，较高者≤600 | 有，视作小反坎 | 否 |
| 无斜段，较高者>600 | 有，保持既有规则 | 是 |

短斜接竖段的转折点由斜线内偏50和竖线内偏50相交确定；向下直锚长度从**原楼层梁顶边缘**起算1000，折点到梁顶的长度不计入1000。梁内1000放不下时保留断口并提示，不改弯锚。小反坎仍仅输出一个倒U，两腿从原梁顶直锚1000；几何扣除与有效锚固支撑分开，避免重画普通纵筋或误扩大支撑范围。

## 点筋规则

- 沿用目标DWG：S-REIN-POINT、颜色30、Continuous、ByLayer；闭合双半圆多段线中心线直径50、宽50，实际外径100。
- 阳角由实际纵筋形成，弯锚阳角不作为固定点。外端角点固定；阴角延伸交点保留水平延伸段与竖向原段一侧的红点，两个青点候选参与重排。
- 点筋置于轮廓内、纵筋内侧，与宽35纵筋边缘相切；点心距该纵筋中心线67.5。原打叉支撑内禁止完整圆形侵入。
- 固定角点与400收尾点作为分布区间的头尾。400为点心到有限支撑边缘线的最短距离；遇真实纵筋自由端时为点心到端点的实际距离。斜筋不是沿斜线简单退400；直筋端部因横向67.5偏距，沿筋退距约394.3。
- 普通点排以实际支撑及有效梁顶延伸区为收尾边界。倒U自己的点排以原打叉梁边为界，允许在未打叉上部布点。小反坎不成为其他点排的支撑边界。
- 分布中心路径与纵筋平行；连续转折连接后计算路径长度L。区间数n=ceil(L/800)，中间等分为L/n；800允许取等号，固定点不移动。中途未固定的转折不作为自由端再退400。
- 倒U顶部两点仍与U自身相切，保留用户允许压到其他锚固筋的例外；不将该例外推广到整排点筋。其余点检查筋碰撞、点间重叠和轮廓越界。

## 已发现的约束冲突

真实建筑样例：固定红点已保留、青点候选重排，最终23个点。左侧阴角水平延伸端退400后的候选会压到竖向筋；倒U腿的400收尾点会压到内侧40的斜筋竖直锚固段。这些区间无法同时按当前规则收尾和避让，因此提示坐标、保留固定点，不移动固定角点或扩大压筋例外。另有一条在轮廓处中断的局部点排没有合法固定终点，明确提示，不把截断位置当纵筋自由端。

**有提示不代表该区间已满足≤800排满。** 具体记录见 `tests/precision-interface-distribution36.txt`。无斜段的矮小反坎若固定顶角点已经离梁顶不足400，固定点优先保留并报告冲突。

## 验证与限制

AutoCAD 2020/.NET Framework4.7.2编译；167项后台几何/回归检查（含原纵筋128项）通过。另9份实际DWG命令测试生成23/23/7/6/1/0/7/8/2个点筋，重复执行数量不变、纵筋实体数据不变；再次读取输出DWG验证样式、实际外径100、有限纵筋相切、完整圆不入打叉区、点间不重叠及U顶部例外。

`tests/native-commands36.json`、`native-validation36.txt`、`offset-results.txt`是验证记录；`tests/final-run/*-points36-final.dwg`是最终发布DLL的输出，`points-preview36.png`及`short-roof-preview36.png`依据DWG坐标绘制，非CAD截图。原参考DWG未覆盖。tests根目录内的points36 DWG属于中途调试输出，以final-run内文件为准。

输入仍要求完整四倍轮廓及宽35、XY平面的直线纵筋多段线。锚固身份通过36规则重新计算后匹配实际纵筋；任意手工改形的锚固筋尚无独立语义标记，不保证全部识别。此版本新增分布算法是几何制图规则，不添加用户未指定的配筋设计参数。
