# 点筋布置阶段：35版纵筋阳角与弯锚排除

本轮在独立副本 `experiments/point-corners/` 修正点筋规则，当前35版尚未验收。稳定主项目和锚点33不变；34源码、发布文件和验证记录已保存在history/1.0.0.34。用户明确：阳角是纵筋形成的阳角，不是建筑轮廓的阳角；普通弯锚和斜筋转竖直的锚固段不参与角点生成，倒U顶部两角保留。

## 当前规则

1. 实际目标DWG只读检查了23个点筋实体：S-REIN-POINT图层、颜色30、CONTINUOUS线型、图层默认线宽；实体为ByLayer，两个bulge=1的半圆组成闭合轻量多段线，中心线直径50、宽50，实际外径100。此处沿用用户此前确认的实际外径100，不把它改成外径50。
2. 本命令生成的完整点筋圆形不得侵入原始打叉支撑。即使圆心在外，只要圆边越入支撑也拒绝；允许圆边恰好与支撑边界外切。
3. 沿用纵筋的BeamTopRegion/BeamTopRebar识别梁上方未打叉的竖直延伸区域，该区域允许布点，先保留倒U顶部两个阳角点筋。排除判断使用OriginalSupports，不能使用已经合并梁顶区域的EffectiveSupports。
4. 角点候选完全来自图中实际纵筋的转折及有限线段交点，包括非顶点处的T形、十字或斜交。各夹角小于180度的角区分别检查，不延长互不相接的线段。闭合纵筋按自身环判断内侧和阴阳角；建筑轮廓不提供角点，只限制圆形不能越出材料区域。圆须与形成角的两条有限纵筋边缘相切，圆心到中心线为50+35/2=67.5。本轮不布置沿边分布点筋。
5. 倒U顶部点筋仍与倒U的水平顶边和竖直侧边相切，用户明确允许其压到其他斜筋转下来的锚固筋，不为避让而向内移动。这一例外不允许侵入原始打叉支撑或越出材料轮廓；其他普通阳角仍检查纵筋碰撞。
6. 空间不足、切点落在实际线段以外、圆不完全在轮廓内的候选跳过并反馈数量。点筋之间避免相互重叠。重复运行对相同样式点筋去重，不重画已有纵筋。
7. 根据当前33版纵筋计算上下文中的AnchorEnds识别Bent和VerticalBent：从原断口到支撑入口、转折及弯段末端的实际重合线段，均从候选线段中剔除。它们既不生成自身弯角点筋，也不与其他纵筋生成交点点筋；弯锚前的普通筋段继续参与。直锚不被误删。倒U自身不属于此处弯锚，两角及已确认的允许重叠例外保留。剔除仅作用于内存中的候选线段，不修改纵筋实体。

## 代码定位

下列文件均在 `experiments/point-corners/src/AutoCADPlugin/`。

| 内容 | 文件 / 方法 |
| --- | --- |
| 新命令、选择、输入纵筋校验、事务和输出信息 | `PointRebarCommands.cs`：`PointRebar`，命令SD_POINT_REBAR |
| 阳角候选、内切圆、禁入及碰撞、倒U例外 | `CornerPointRebar.cs`：`Create`、`TryTangent`、`IntersectsSupport` |
| 纵筋有限线段实际求交、交点分出的方向 | `PointBarJunction.cs`：`Intersect`、`Rays` |
| 弯锚/转竖直锚固段排除，保留弯锚前普通筋段 | `PointAnchorExclusion.cs`：`Read`、`Subtract`、`IsUPath` |
| 原生实心点筋样式、图层、重复运行去重 | `PointRebarWriter.cs`：`Write` |
| 复用的梁顶区域及支撑身份 | 原33版 `OffsetRebar.Create`、`BeamTopRegion`、`BeamTopRebar`；计算上下文，不写入纵筋 |
| 回归和新增点筋测试 | `tests/OffsetChecks.cs`、`tests/PointCornerChecks.cs`、`tests/PointJunctionChecks.cs` |

只支持已放大四倍、宽35、XY平面的直线纵筋多段线。须框选完整轮廓、支撑和已有纵筋；纵筋算法的轮廓输入限制继续适用。弯锚身份由33版规则重新计算并与实际线段匹配；任意人工移位或改形的锚固段没有可靠的语义标记，不能宣称可识别所有手工绘制的弯锚。新交点是否布点仍受实际空间、打叉区域禁入和其他碰撞检查约束。

## 使用与验证

保存并重启AutoCAD，NETLOAD试验目录 `artifacts/Debug/AutoCADPlugin-1.0.0.35.dll`，SD_VERSION确认版本。先删除本次大样的旧版点筋，保留轮廓、支撑和纵筋，避免34版错误位置残留；35不会自动删除人工或旧版点筋。已有33版纵筋可保留。执行SD_POINT_REBAR，框选完整四倍轮廓、支撑及纵筋，回车。

148项AutoCAD后台检查通过（包含原128项纵筋检查）。新增覆盖：钢筋角点与建筑角点分离、纵筋闭合L形自身阴角、非顶点处十字/T形/斜交、断开线段不延伸、普通弯锚和转竖直锚固的角点及交点排除、反向顶点顺序，以及弯锚前的普通筋段保留。6个命令样例生成12/12/5/2/1/0个点筋，纵筋实体数据不变，重复运行数量稳定。倒U两角保持；短竖段只有50的极小样例不满足相切条件，0点为预期。

当前样例为 `tests/*-points35.dwg`；`*-points35.txt`为命令实体记录，`points-preview35.png`按实体坐标绘制，非CAD截图。34版相关文件为历史结果，冻结副本在history/1.0.0.34。原参考DWG未保存覆盖。分布点筋待用户后续给定。
