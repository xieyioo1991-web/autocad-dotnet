36已按用户要求冻结为 [点筋试验回退锚点](../../anchors/1.0.0.36/README.md)。36包含已知问题，归档不等于全部规则验收。37从36复制到本目录，试验效果待用户查看；稳定33、36原目录和冻结快照均不改写。本轮不改变建筑轮廓或纵筋生成算法。

## 加载与测试

1. 保存测试图副本并重启AutoCAD 2020，使用NETLOAD加载 `artifacts/Debug/AutoCADPlugin-1.0.0.37.dll`，以 `SD_VERSION` 核对37。
2. 删除本大样旧点筋，保留36生成的洋红纵筋、四倍轮廓和支撑。此次不需要重画纵筋。
3. 执行 `SD_POINT_REBAR`，框选完整轮廓、支撑及纵筋；检查命令行警告和图面。
4. 相同点重复执行不增加数量；旧布局与新布局不一致时拒绝混排，需要先清理旧点筋。警告区间未补齐，不能只按总点数判断已经布满。

## 本轮尝试解决的四个问题

| 用户反馈 | 37试验处理 |
| --- | --- |
| 左下水平纵筋没有分布点 | 所属点排的400尾点允许压到其他路径的竖向穿越筋，不因该穿越筋取消整排 |
| 梁顶倒U两条竖筋没有分布点 | U自己的点排以真实梁顶400为尾点，允许压到其他路径的锚固筋，恢复两侧竖排 |
| 固定绿色角点旁堆积多个点 | 真实转折角固定；内部交点不再锁死，从真正固定头点到400尾点重新等分 |
| 内部交点出现多余两点 | T/X及内部斜交不单独添固定角点；只有正常均布需要该位置时才可能在那里出现普通分布点 |

内部交点统一参与均布，包括36曾固定的红点。同一纵筋相邻原始段形成的真实转折和倒U顶部仍固定。两根独立筋恰好首尾接成两个方向的L角可以固定；存在第三、第四方向则属于T/X，不固定。普通弯锚和斜筋转竖直等锚固段不提供角点，但必须计入完整交点方向，避免把带锚固第三臂的T误判成L。

**37允许图面上的点筋与其他路径的穿越纵筋、锚固筋重叠。** 点筋仍与所属纵筋相切，不侵入所属路径的其他段；固定转折角仍与构成该角的筋相切。这个放宽是本次解决水平漏布、U腿漏布的试验调整，尚不是用户验收后的通用规范。

## 沿用的尺寸和约束

- 点筋样式仍为S-REIN-POINT、颜色30、Continuous、ByLayer；双半圆闭合多段线中心线直径50、宽50，实际外径100。与宽35纵筋内边缘相切，圆心距纵筋中心线67.5。
- 实际打叉支撑内禁止完整点圆侵入。普通点排在真实支撑或有效梁顶延伸边缘外400收尾；倒U自己的点排只以真实支撑为界。400为圆心到有限边缘的最短距离。
- 无支撑边界而遇真实自由端时，圆心到该端点的实际距离400；中途转折不是自由端。直筋端部因横向67.5偏距，沿筋退距约394.3。
- 固定头尾之间按中心路径等分，区间数为ceil(L/800)，间距≤800且尽量接近800，固定点不动。
- 所属路径碰撞、点间重叠、轮廓越界仍检查。发生冲突时保留固定点并提示，不能跳过中间点后仍声称全排满足800。
- 纵筋所有算法均与36一致，包括梁顶较高竖边600判断、短斜接取消U并从梁顶直锚1000、小反坎有U但不作延伸区，以及其他既有锚固规则。

全部尺寸均为建筑轮廓放大四倍后的图上尺寸。
