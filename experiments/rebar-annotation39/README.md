# 39版：纵筋标注试验

2026-09-26，用户暂时验收点筋布置阶段，指定38作为新锚点，并授权在独立副本开展纵筋标注。38冻结在 `../../anchors/1.0.0.38/`，33稳定主目录和所有历史锚点不改写。39尚待用户查看效果，不自动晋升锚点。

## 使用

1. 保存图纸并重启AutoCAD，NETLOAD `artifacts/Debug/AutoCADPlugin-1.0.0.39.dll`，用 `SD_VERSION` 核对。
2. 保留DLL旁的 `Fonts/`，包含实例1所用名称的 `tssdeng.shx` 和 `hztxt.shx`，不需要改CAD全局支持路径。
3. 在已有四倍结构大样上执行 **`SD_REBAR_LABEL`**，框选完整大样，包括纵筋、点筋、轮廓、支撑及原梁板文字和引线。无需删除点筋或重画纵筋。
4. 每条完整S-REIN宽35直线多段线生成一组标注。连续弯折的同一多段线计作一根，不按每个小线段重复标注。重复执行会替换本命令已有标注，可重排。

## 本轮规则

- 每根纵筋一条带文字的指引，指引起点位于这根纵筋的实际有限线段上；文字固定为字面量 `%%1328@150`。不计算或选择钢筋型号、直径、间距。
- 文字及引线属性来自用户原始实例1结构DWG的153/155/159号文字、151/152/154/156/157/158号Line。文字是S-TEXT、TSSD_Label、tssdeng.shx＋hztxt.shx、字高250、宽度系数0.7、倾角0、随层白色。钢筋引线是原生Line、S-OTHER-THIN、随层绿色（ACI3）、随层连续线、随层线宽。相关图层线宽为Default，与实例一致。
- `%%132`是原样例字体的钢筋符号编码，数据库不替换成普通Φ或直径符号。字体取本机已有文件并随试验目录附带；来源、哈希、参考实体属性见 `assets/` 与 `tests/reference-annotation-style.txt`。本机不同软件的同名SHX存在不同文件版本，选取来源已明确记录；未声称字体二进制嵌入在原DWG中。
- 梁板文字与纵筋文字在同一次布局中联合调整。保留梁板指引的白色表达，字体统一为样例同款。为适应文字排版采用左基线定位；不照搬样例文字的右对齐坐标。
- 从各筋有限段、支撑内点生成水平或折线加水平底线的候选位置；按实际SHX字形范围避开文字、点筋、轮廓及其他实体，优先少穿筋、少交叉、短引线。经过多种排布顺序和共同调整选择布局；并非对任意密集图保证全局最佳美观。
- 不能让全部文字及其指引避开文字范围时，整次失败回滚并提示。不会漏掉某根纵筋后声称完成。不同引线之间的交叉以及穿越轮廓属于优化项，复杂图形仍可能发生，需查看实际出图。
- 本轮主动重排纵筋及梁板三类标注；其他可见文字/尺寸作为障碍保留位置，避免无依据拆动人工尺寸。未框选但靠近大样的实体也参与避让。
- 38的旧梁板标注没有关联标记，通过准确文字、图层及通向支撑的1—2段连接关系迁移。轮廓/支撑角色实体及打叉对角线不会作为旧引线删除；识别不清则整次提示失败。
- 新标注通过SD_ANNOTATION的原生1005句柄关联所属纵筋/支撑，整图复制时由AutoCAD重映射。新标注不写入Contour/Support角色，后续识别轮廓不会读到引线。
- 同名TSSD_Label若字体配置冲突，使用同字体的TSSD_Label_SD39，不改写其他用途的同名样式。两个标注图层的颜色、连续线和默认线宽统一到样例定义；不会关掉或解锁图层。

## 代码定位

| 内容 | 文件 |
| --- | --- |
| 命令、事务和用户消息 | `src/AutoCADPlugin/RebarAnnotationCommands.cs` |

## 验证与回退

- .NET Framework 4.7.2编译，0错误0警告。
- 190项原有几何/纵筋/点筋检查通过，记录在 `tests/regression/offset-results.txt`。
- AutoCAD2020后台引擎在11份38输入DWG上验证：所有纵筋逐根覆盖、原生样式、引线确实接触所属筋、实际文字范围无重叠、引线不穿文字、旧梁板标注清理、重复执行稳定、纵筋/点筋/支撑叉号/轮廓保持不变。
- 额外验证失败事务回滚、原生整图复制1005句柄重映射、大坐标排布和未选中邻近文字避让。见 `tests/annotation39-results.txt`。
- 生产命令实际执行两次，原纵筋/点筋DXF数据前后相同；原生绘图引擎输出PDF并检查预览，未用近似字体图片代替字体检查。见 `tests/production39-validation.txt`、`production39-unchanged.txt`、`production39.pdf`、`precision39.pdf`。
- 原始用户DWG只读；所有输出在试验tests目录。新增标注输出文件名为 `*-labels39.dwg`。
- 如效果不好，先保留39图纸和修改，再加载38锚点DLL。切换DLL不会删除已经画出的标注；建议在38图纸副本上试用39，以便直接返回38图纸。
