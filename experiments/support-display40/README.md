# 40版：建筑轮廓阶段的支撑叉线显示

由39独立复制，保留39逐根纵筋标注功能。用户尚未验收39或40，38继续作为当前锚点，不覆盖历史目录。

## 新规则

- SD-REGION区域仍使用原有宽高分类：高>2×宽为楼层梁，宽>2×高为楼层板，其余沿用楼层梁兜底。
- **楼层梁：生成两条虚线对角线。** 保持原S-OTHER-THIN图层及白色；实体单独使用SD-SUPPORT-DASH虚线，不将整个图层设为虚线。
- 虚线节奏取实例1结构大样的__DASH：原始线型0.25实段/0.10空段配LTSCALE1000。四倍结构图中实际为250实段/100空段；生成时用实体线型比例补偿当前LTSCALE，不修改全图LTSCALE。
- **楼层板：不生成叉线实体，包括不可见叉线也不生成。** 封闭轮廓、楼层板文字及引线保留。Support角色仍在闭合多段线上，辅助判断由该边界完成，不依赖两根对角线。
- 只改变支撑的显示；楼层板仍是原始支撑区域，纵筋锚固、点筋禁入和400收尾等既有语义继续保留。“打叉区域”在旧配筋文档中应理解为支撑区域，不能因板没有可见叉线就允许配筋进入。

## 使用与定位

保存并重启AutoCAD，NETLOAD `artifacts/Debug/AutoCADPlugin-1.0.0.40.dll`，保留同目录Fonts文件夹。SD_VERSION核对40，然后用 **SD_AUTO_DETAIL** 重新生成轮廓大样。

本规则用于新生成大样，不会在加载DLL时自动删除旧图的板叉线或改变旧梁叉线。不要在旧大样上再次叠画；在空白位置生成对照。

- `src/AutoCADPlugin/DetailWriter.cs`：WriteSupportCross与文字使用相同分类，板直接跳过，梁生成两条虚线。
- `SupportCrossStyle.cs`：定义原生虚线及实体比例；同名线型冲突时提示，不改写不兼容定义。
- `SupportClassification.cs`、`WriteControlBoundary`、OutlineRole=Support不变；SD_AUTO_DETAIL的提取器和4倍转换不变。
- 39继承的纵筋标注功能入口仍是SD_REBAR_LABEL，规则见[39说明](../rebar-annotation39/README.md)。
